# Galaxy Strike - 2D Space Shooter

## Description
**Galaxy Strike** is a modern, responsive, 2D vertical browser space shooter game created from scratch using Vanilla JavaScript, HTML5, and HTML5 Canvas.

## Features
- **Zero External Dependencies**: Works completely offline out of the box.
- **Web Audio Synthesizer**: Custom procedural sound generator using Web Audio API (Laser, Hit, Explosions, Power-ups).
- **Responsive Controls**: Fully supports Desktop (Keyboard/Mouse) and Mobile Touch devices (Touch-drag + On-screen buttons).
- **Procedural Asset Engine**: SVGs embedded and converted in-memory guarantees zero missing PNG/404 image errors.
- **Dynamic Difficulty**: Escalating enemy waves, movement speed, and Boss battles every 5 levels.
- **7 Unique Power-Ups**: Fast Fire, Double Fire, Big Plasma Fire, Rapid Fire, Kinetic Shield, Extra Life, and Score Multipliers.
- **Persistence**: High scores saved in browser `localStorage`.

## Controls
### Desktop
- **Move Left:** `A` or `Left Arrow` or `Mouse Move`
- **Move Right:** `D` or `Right Arrow` or `Mouse Move`
- **Shoot:** `Spacebar` or `Mouse Click`
- **Pause / Unpause:** `P` or `ESC`

### Mobile
- **Touch & Drag:** Touch anywhere on screen and drag to move ship horizontally.
- **On-Screen Touch Buttons:** Dedicated `◄ Left`, `► Right`, and `FIRE` buttons.

## How to Run
1. Unzip `Galaxy-Strike.zip`.
2. Open `index.html` directly in any web browser (Chrome, Firefox, Edge, Safari).
3. No server or internet connection required!
